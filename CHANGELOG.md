# Changelog

## 1.0.0 — Development candidate

- Native menu-bar history, immediate text preview/editing, row Copy, multi-selection, and keyboard actions.
- Permission-aware clipboard capture, SQLite/FTS5 history, pinning, retention, and deletion safeguards.
- Local privacy settings, application exclusions with documented limitations, optional automatic paste, and launch at login.
- Validated settings/history import/export and optional password-encrypted AppleArchive backups.
- Regression tests, fixture UI tests, a 10,000-entry benchmark, universal packaging, and CI preparation.

Public release is pending the verification and distribution gates in VERIFICATION.md.
