# Clipboard 1.0.0

A compact native clipboard manager for macOS 14 and newer, with universal Apple Silicon and Intel binaries.

## Included

- Menu-bar popup, global shortcut, outside-click dismissal, and visible recording controls.
- Compact 40/60 list/preview layout; fitted text and image previews.
- Immediate text editing, explicit Save, pinning, row Copy, and editable combined copying.
- Search and filters, local SQLite history, retention, deletion Undo, and app exclusions.
- Optional automatic paste with a direct Accessibility settings link and permission rechecking.
- Validated backups, including optional password encryption.

## Install

Download the universal DMG, open it, and drag Clipboard.app into Applications. Or unzip the universal ZIP and move the app into Applications. Quit any older copy before replacing it. Start local history after the first launch; the default shortcut is Option-Command-V.

For automatic paste, enable it in Settings → General, open Accessibility Settings, and allow the installed Clipboard app. Return to Clipboard to refresh permission status. Copy works without this permission.

## Signing and verification

This release is ad-hoc signed, **not Developer ID signed or notarized**. macOS may block first launch. Review [Apple’s guidance](https://support.apple.com/en-us/102445) and only allow an app you trust. Do not disable Gatekeeper globally.

SHA256SUMS verifies the ZIP and DMG. BUILD-INFO.json records the source commit, version, architectures, build tools, and signing/notarization status.

The core and native integration test suite passes locally; fixture UI tests compile. Native text and image fixture renders were inspected. Full interactive UI automation, macOS 14/Intel runtime coverage, and Instruments performance measurements remain pending. Universal compilation does not establish Intel runtime compatibility.

Clipboard does not encrypt its local history database. See the [privacy documentation](https://github.com/aagzamov-dev/Clipboard_macos/blob/v1.0.0/docs/PRIVACY.md) before storing sensitive material.
