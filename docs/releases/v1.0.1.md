# Clipboard 1.0.1

A compact native clipboard manager for macOS 14+, built for Apple Silicon and Intel.

- Fix the popup’s first-open focus transition and first-click preview of the selected item.
- Keep selection stable as new clipboard entries arrive; use cached entries for ordinary selection.
- Fix automatic paste focus restoration and distinguish disabled paste, missing permission, and unavailable destinations. Add a clear Permissions page.
- Add authenticated updates from GitHub Releases with Sparkle. Daily checks can be disabled in Settings → Updates; Check for Updates is available there and in the menu-bar menu. You choose when to install and restart.
- Preserve unsaved individual and combined edits before restarting for an update.

## Install

Download the universal DMG and drag Clipboard.app into Applications. Quit an older running copy before replacing it. **v1.0.0 users must install this update manually once**; later releases can use the in-app updater.

This release is **ad-hoc signed, not Developer ID signed or notarized**. The updater separately verifies Ed25519 signatures on the feed and downloads. Those signatures do not provide Apple notarization. If Gatekeeper blocks the app, use System Settings → Privacy & Security → Open Anyway. If necessary, and only after verifying and trusting the download, remove quarantine for this app:

```sh
xattr -dr com.apple.quarantine "/Applications/Clipboard.app"
```

Automatic paste is optional: enable it in Settings → General and grant Accessibility access to the installed copy. If a previous grant is stale after replacement, remove the old Clipboard entry and add the installed copy again. No Input Monitoring or Screen Recording permission is needed.

## Privacy and verification

History remains local and unencrypted. Update checks contact GitHub; clipboard contents are never sent and system profiling is disabled. Encrypted backups remain optional. See [Privacy](https://github.com/aagzamov-dev/Clipboard_macos/blob/main/docs/PRIVACY.md).

Core and native integration tests, universal builds, signature checks, and fixture UI compilation are required for publication. The user confirmed automatic paste works in local build 3. Full macOS/Intel runtime coverage, authenticated UI automation, Instruments measurements, and a real future-version installation remain outstanding; see [Verification](https://github.com/aagzamov-dev/Clipboard_macos/blob/main/VERIFICATION.md).
