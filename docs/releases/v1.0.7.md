# Clipboard 1.0.7

Fix the large empty space between image thumbnails and their labels. Short text labels now also stay beside their icons, while Preview and Copy remain aligned to the right edge. The fix applies across popup widths and reused image/text rows.

Choose **Check for Updates…** in Clipboard to install and restart. History and preferences are preserved. Universal Apple Silicon/Intel downloads support macOS 14 and newer. The existing updater signing key is unchanged; bundle build is 10.

## Verification and signing

All 31 core and 37 platform tests pass locally, including the regression that reproduces the misplaced labels and checks spacing across row widths, short/long text, and thumbnail/icon changes. The native fixture render was visually checked, and the local Release build passed. Release validation compiles fixture UI tests, packages universal ZIP/DMG assets, and verifies update signatures with tamper rejection.

This release remains **ad-hoc signed, not Developer ID signed or notarized**. macOS may require renewing the app’s Accessibility grant after updating. Live destination-app acceptance, full OS/hardware coverage, and Instruments performance measurements remain unverified as described in VERIFICATION.md.
