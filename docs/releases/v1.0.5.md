# Clipboard 1.0.5

- Choosing a history item automatically pastes it into your previous app. Remove the separate automatic-paste switch and the extra “Allow automatic pasting?” confirmation.
- Existing saved “off” values no longer block pasting. Other preferences and clipboard history are preserved.
- Permissions shows macOS Accessibility and Command-V event access directly. Copy remains available without Accessibility access.

Use **Check for Updates…** to install this release.

## Permission limitations

macOS Accessibility permission is still required to send Command-V. This release remains **ad-hoc signed, not Developer ID signed or notarized**. An update can invalidate an older grant. If access is blocked, remove the old Accessibility entry and add the exact running Clipboard app again. No Input Monitoring, Screen Recording, or Full Disk Access is required.

The update archive and appcast retain the existing Ed25519 signing key.
