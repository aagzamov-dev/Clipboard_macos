# Clipboard 1.0.6

## Daily history, easier navigation

- Open to Today by default. Use the left arrow for Yesterday and earlier days, and the right arrow to return toward Today. All history remains available in the date menu; older entries are preserved.
- Keep browsing and editing steady while new clips arrive. A new-items button lets you refresh when ready.
- Reuse the bounded history cache between openings, prefetch upcoming pages, update newly inserted rows, and reuse matching counts until the database changes.
- Check for the latest copied item when opening without increasing background polling.
- Remember popup size and position per display and preview mode. Include the larger local popup layout and image thumbnails in history rows.

## Faster everyday actions

- Paste plain text with Shift-Enter from the list or Command-Shift-Enter from the editor.
- Press Command-1 through Command-9 from the list to paste the corresponding first nine results.
- Start typing from the list to search; Down Arrow returns from search to list navigation.
- Filter pinned entries and see readable source-app names.
- Use Text actions to trim whitespace, remove blank lines, or change case. These edit a draft; Save explicitly to change history.
- Right-click the menu-bar icon to pause recording for 5, 15, or 60 minutes, then resume automatically.

## Updating

Choose **Check for Updates…** in Clipboard, then install and restart. Existing history and preferences are preserved. The update archive and feed retain the existing Ed25519 signing key. Apple Silicon and Intel downloads are included for macOS 14 and newer.

## Signing and verification

This release is **ad-hoc signed, not Developer ID signed or notarized**. macOS can invalidate an existing Accessibility grant after an update. If automatic paste becomes blocked, remove the old entry and add the exact running Clipboard app again in Accessibility settings. No Input Monitoring, Screen Recording, or Full Disk Access is required.

Local validation passed 31 core and 37 platform tests and the Release build. Coverage includes calendar-day boundaries, daily navigation, stable pagination during new captures, count-cache invalidation, plain-text paste preserving rich history, and deferred capture during draft editing. Native fixture layouts were rendered and inspected. Release validation also compiles fixture UI tests, builds universal ZIP/DMG artifacts, and verifies update signatures and tamper rejection.

Real destination-app paste acceptance, the complete OS/hardware matrix, and Instruments latency, memory, and energy measurements remain unverified. See VERIFICATION.md.
