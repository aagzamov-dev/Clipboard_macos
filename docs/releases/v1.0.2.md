# Clipboard 1.0.2

- New minimal clipboard app icon, with native sizes from 16 to 1024 pixels.
- Clear Permissions page with separate Accessibility and Command-V event access, live status, recovery steps, and the exact running app location.
- **Test automatic paste…** checks real event delivery to a separate included test app, using a private clipboard. Your real clipboard and other apps' documents are untouched.
- Safer paste activation: wait for Clipboard to relinquish focus and the destination to settle, recheck access, and dispatch one paste command.
- Signed GitHub updates continue from v1.0.1. Use **Check for Updates…** or wait for the daily check.

## Permission recovery after updating

This release remains **ad-hoc signed, not Developer ID signed or notarized**. macOS may invalidate an older Accessibility grant after updating. An enabled switch alone does not prove the running copy is authorized.

Open **Settings → Permissions**. If Command-V is blocked, remove the old Clipboard entry from System Settings → Privacy & Security → Accessibility. Use **Show this app in Finder** to locate the running copy, add that app with **+**, enable it, then quit and reopen Clipboard. Run **Test automatic paste…** to check the result. Keep one installed copy in Applications. No Input Monitoring, Screen Recording, or Full Disk Access is needed.

Stable publisher identity across future updates requires Developer ID signing. Ed25519 update signatures authenticate downloads; they do not replace Apple code-signing identity or notarization.

## Install and verification

Existing v1.0.1 users can install through the in-app updater. v1.0.0 users need a manual installation once. Download the universal DMG, quit the running copy, and drag Clipboard.app into Applications. History and preferences remain outside the app bundle.

If Gatekeeper blocks a download you have verified and trust, use Open Anyway in System Settings → Privacy & Security. The app-specific quarantine command remains:

```sh
xattr -dr com.apple.quarantine "/Applications/Clipboard.app"
```

Automated checks cover storage, private pasteboards, permission-state disagreement, access revocation during paste, settled activation, and exactly-one event dispatch. Universal packaging, nested signatures, and signed archive/feed tamper rejection are release gates. Full hardware/OS coverage and Instruments performance measurements remain pending; see VERIFICATION.md.
